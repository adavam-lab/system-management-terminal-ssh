# Cómo contribuir

¡Gracias por querer mejorar XSS Manager!

## Licencia de las contribuciones

Este proyecto está licenciado bajo la **GNU Affero General Public License v3.0 o posterior** (`AGPL-3.0-or-later`). Consulta [LICENSE](LICENSE) y [NOTICE](NOTICE).

Al enviar un pull request, parche o cualquier otra contribución aceptas que:

1. Tu contribución se publica bajo la misma licencia `AGPL-3.0-or-later`.
2. Tienes derecho a aportar ese código (es tuyo o tiene una licencia compatible).
3. Conservarás los avisos de copyright y la atribución al autor original que aparecen en [NOTICE](NOTICE).

## Qué implica la AGPL para quien modifica el proyecto

- Puedes usar, estudiar, modificar, redistribuir e incluso vender el programa.
- Si **distribuyes** una versión modificada (instalador, binario, fork), debes publicar su código fuente completo bajo `AGPL-3.0-or-later`.
- Si ofreces una versión modificada **a través de una red** (por ejemplo, como servicio web), también debes ofrecer su código fuente a quienes la usen.
- Debes indicar que lo modificaste y conservar la atribución: *"Basado en XSS Manager, creado por MadXcorp - ADAVAM"*.

## Encabezado para archivos nuevos

Si creas un archivo de código nuevo, añade al principio:

```js
// SPDX-License-Identifier: AGPL-3.0-or-later
// Copyright (C) 2026 MadXcorp - ADAVAM
```
